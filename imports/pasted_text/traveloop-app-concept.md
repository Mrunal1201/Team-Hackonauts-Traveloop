Create a modern, visually stunning, AI-powered travel planning web application called **Traveloop** for a hackathon prototype.

The application should feel like a mix of:

* Airbnb
* Google Travel
* Notion
* TripAdvisor
* Apple-level clean UI

Design a FULLY RESPONSIVE prototype with smooth animations, glassmorphism, gradients, maps, cards, and modern dashboard aesthetics.

---

## CORE IDEA

Traveloop is a smart travel planning platform where users can:

* Plan multi-city trips
* Build itineraries visually
* Discover destinations and activities
* Estimate travel budgets automatically
* Share trips publicly
* Organize notes and packing lists

The UI should look premium, futuristic, and hackathon-winning.
